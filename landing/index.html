AgentWarden

Give every AI agent an identity, a scoped role and spend limits, with an audit trail.

Signed, expiring agent tokens; role policies where an explicit deny always wins; per-scope spend caps; and an append-only audit log.

Request access

Who it's for

Engineering and security teams putting agents into production.

The problem

Agents run on shared API keys with no identity, so nobody can say which agent did what or stop one from overreaching.

Quickstart

Python 3.10+, no other dependencies. Your release archive includes the wheel and examples.

pip install agentwarden-0.1.0-py3-none-any.whl
agentwarden --store okta.json role add support --allow read:crm/* --deny read:crm/payroll*
agentwarden --store okta.json agent add bot1 --owner a@x.com --role support
agentwarden --store okta.json agent list
